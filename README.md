An AI powered code review tool built with MERN stack and Google Gemini API that analyzes your code for bugs, security issues, performance problems and best practices with an overall quality score.
Features

JWT authentication with HTTP only cookies
AI code review using Google Gemini API
Bug, security, performance and best practices analysis
Code quality score out of 10
Improved code suggestions
Review history
Multiple language support
Rate limiting on auth routes

Tech Stack

Backend — Node.js, Express.js, MongoDB
Frontend — React.js, Monaco Editor, Tailwind CSS
AI — Google Gemini API
